Official public distribution and release channel for the **IDR (Identity & Document Reader)** Android application.

---

## 📱 Features

- **Offline Identity Management**: Fast, secure local identity storage and verification.
- **Document & Card Scanning**: Real-time scanning and recognition with high precision.
- **Offline Hardware Wallet**: Sequential cryptographic token tracking with atomic balance ledgers.
- **Peer-to-Peer Offline Top-Ups**: Digital signatures using NIST P-256 (secp256r1) ECDSA.
- **Automatic In-App Updates**: Built-in silent and automated update checks for seamless new releases.
